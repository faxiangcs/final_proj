01 · Storyline

故事线：从“能不能用 RL”到“哪种奖励值得用”

先读 01 → 04 了解结论，再看实时监控。调参时重点看 05 → 06 和后面的决策表。

  1. 01

    问题 结构化报告

    脑 MRI 报告不是单个标签，而是定位框、影像描述、鉴别诊断三个耦合决策。SFT 只最大化参考 token 的似然，不能直接优化终局定位 F1 或诊断命中。

  2. 02

    方法 token-level MDP

    把报告生成写成序列决策：观测是图像 + 病史 + 指令，动作是下一个 token，奖励在 EOS 后由确定性的定位/诊断分数给出。GRPO 用组内相对优势，不需要 reward model。

  3. 03

    主实验 弱起点 vs 强起点

    从弱 SFT-50 和强 SFT-201 两个初始化各跑 GRPO。test 为 111 张 / 36 例，93.7% 的最终诊断在微调集中没有出现过。

  4. 04

    历史对照 原始奖励

    弱起点 ck100 把 F1@0.5 从 0.146 推到 0.216（CI [+0.015,+0.125]），但 ck100 是看过 test 后选的；强起点 0.401→0.390（CI 跨 0）。诊断和描述没有可靠提升。

  5. 05

    奖励如何改变 GRPO 更新

    同一输入采样四份报告，GRPO 按组内奖励计算相对优势。四份报告同分时，任务奖励项的优势为零，KL 正则项仍可起作用。连续 IoU 奖励能区分部分重叠但尚未达到 0.5 阈值的定位框。

  6. 06

    奖励消融 三组配置 × 三个 seed

    三组都从同一个 SFT-201 开始，并用冻结的 SFT-201 作 KL 参考。依次比较原始奖励、连续定位加诊断奖励、仅连续定位奖励。每个 seed 的 checkpoint 和推荐配置均由验证集选定。

02 · Method

方法：可验证奖励 + GRPO

目标不是证明 GRPO 万能，而是回答：在什么初始化下、哪种可验证奖励值得用。所有奖励都是确定性的、可复算的。

MDP 形式化

观测o = (I, H, P)：图像、临床病史、固定指令
状态s_t = (o, y_<t)：输入 + 已生成前缀
动作a_t：下一个 token
转移s_{t+1} = s_t ⊕ a_t：确定性拼接
终止EOS 或 512 个 completion token
奖励终局奖励 R(o, y)，只在完整报告后计算

这是一个 token-level MDP，但由于输入静态、奖励终局，等价于对完整报告的 contextual bandit；RL 的合理性来自奖励不可微，而不是环境有多复杂。

奖励函数

R_loc = TP / (TP + FP + FN) # box-set Jaccard @ IoU 0.5

坐标归一化、裁剪、NMS、最多 3 个框之后，做一对一贪心匹配。评估用 F1，训练用 Jaccard。

R_diag = 0.95 × (0.7 × s_final + 0.3 × s_diff) + 0.05 × s_fmt

最终诊断 + 鉴别诊断 + 格式检查；没有 caption reward，避免奖励和评测口径错位。

R = R_loc + R_diag ∈ [0, 2] （原始配置）
R_shaped = 0.5 R_loc + 0.5 × 2 Σ IoU_matched / (n_pred + n_gold)

连续项使用重叠为正的一对一匹配，分母计入未匹配框。dense 使用 R_shaped + R_diag，loc_only 只使用 R_shaped。三组均对同一输入的四份报告计算组内优势，并用冻结 SFT-201 作 KL 参考。

      解读边界
      
        
        
          
      • 历史实验为单 seed。后续实验有三个 GRPO seed，共用同一个 SFT-201 初始化和同一测试切分。
        • 
          
      • 后续配置和 checkpoint 在新测试推理前锁定。开发期间看过该测试切分，结果仍属探索性。
        • 
          
      • 三组共用冻结的 SFT 参考。组间比较主要反映奖励配置差异，KL 参考本身的作用需要单独对照。
        • 
          
      • 相对 SFT-201 的差值衡量 GRPO 续训后的变化。此前没有等算力继续 SFT 的对照。
        • 
          
      • box calibration 是 post-hoc，且只在 validation 上拟合；raw 和 calibrated 分开报告。
        • 
          
      • AP proxy 不是标准 COCO mAP；诊断用 keyword alias matching，不是临床等价。
        • 
          
      • NOVA 是 evaluation-only benchmark；本项目只做研究，不构成临床部署证据。
        • 
        
      
      
      
      
      
        
      指标口径
      
        
      
          
      
            
              
      F1@0.5一对一贪心框匹配，IoU ≥ 0.5；评估主指标。
      
              
      Mean IoU仅匹配框的平均 IoU；不惩罚漏检。
      
              
      Diag T1 / T5最终诊断 keyword alias matching 的 Top-1 / Top-5。
      
              
      Zero-variance一个 GRPO 组内奖励完全相同，任务奖励项的优势为 0。KL 项可继续提供梯度。
      
              
      CI主实验：paired case-cluster bootstrap；后续：paired seed-and-case bootstrap。
      
              
      Raw / calibratedcalibrated 的 box scale 只在 validation 上选，test 不参与。
